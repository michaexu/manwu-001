# 适老化 UI/UE 重设计 — 会员领物小程序

## 概述

针对中老年用户群体重设计两个微信小程序（用户端 + 商家端）。核心目标：大字号、高对比、暖色调、大触控目标、简化布局。

---

## 1. 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色（操作/选中） | `#C41E1E` 中国红 | 按钮、选中态、标题 |
| 辅助色（强调） | `#D4A030` 金色 | VIP 标签、积分数字 |
| 页面背景 | `#FFF8F0` 米白 | 暖调基础背景 |
| 卡片色 | `#FFFFFF` 白 | 卡片、表单 |
| 文字主色 | `#2D1B00` 深褐 | 正文、标题 |
| 文字辅助 | `#8B7A66` 暖灰 | 二级信息 |
| 分割线 | `#F0E8DE` 浅金灰 | 分割、边框 |
| 成功 | `#2E7D32` 绿 | 核销成功 |
| 危险/警告 | `#C62828` 红深 | 满额、取消 |

原则：红色用于操作入口和选中态，不做大面积纯红背景。大面积用米白+金点缀保持柔和。

---

## 2. 字体系统

| 级别 | 大小 | 字重 | 用途 |
|------|------|------|------|
| 特大数字 | 80rpx | Bold | 积分、名额数字 |
| 大标题 | 42-44rpx | Bold | 页面主标题、顶栏标题 |
| 中标题 | 36-40rpx | Bold/SemiBold | 活动标题、模块标题 |
| 正文 | 32-34rpx | Regular | 按钮文字、正文、输入框 |
| 小字 | 28-30rpx | Regular | 辅助信息、标签文字 |
| 极小 | 26rpx | Regular | 不鼓励使用 |

---

## 3. 间距与尺寸

- 页面左右安全边距：**24rpx**（比标准30rpx略窄，内容更宽）
- 卡片内边距：**32rpx**
- 卡片间间距：**24rpx**
- 按钮高度：**90rpx**（原 ~72rpx）
- 最小触控目标：**88rpx** × 88rpx
- 底部固定栏高度：**120rpx**
- 圆角：大圆角 **20-24rpx**，小圆角 **12-16rpx**

## 7. 实现方式

- 纯 WXSS 改造，不涉及 JS 逻辑变更
- 每个页面独立 .wxss 覆盖
- 全局样式统一在 `app.wxss` 调整
- 图片资源（tabIcon 等）替换为红金配色版本

### 7.1 修改范围

**app.wxss（两个小程序）：** 颜色变量、按钮、卡片、标签、加载、空状态
**app.json（用户端）：** tabBar 配置选中色改为 `#C41E1E`
**每个页面 .wxss：** 按设计稿调整字号、间距、颜色
**每个页面 .wxml（少量）：** 涉及布局结构调整的页面（首页活动卡片、详情名额区、数据看板统计卡片）

### 7.2 不改部分

- 所有 .js 逻辑文件
- 后端 server 代码
- API 接口数据格式
- 不新增或删除功能模块

---

## 8. 不做事项

- 不新增页面或功能模块
- 不改动业务逻辑
- 不改数据流或 API
- 不改动图标图片资源（只替换颜色，可后续优化）
